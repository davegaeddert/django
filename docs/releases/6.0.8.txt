==========================
Django 6.0.8 release notes
==========================

*Expected August 4, 2026*

Django 6.0.8 fixes several bugs in 6.0.7.

Bugfixes
========

* Fixed a regression in Django 5.2 that caused a crash of
  ``QuerySet.distinct(*fields)`` combined with ``order_by()`` and ``values()``
  when two lookup paths resolved to the same column (:ticket:`37222`).
